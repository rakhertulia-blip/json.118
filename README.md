Описание проекта : программа предназначена для ведения журнала тестовых проверок проекта ЕКЕВ
Программа:просмотр списка проверок , добавление новой проверки , изменение статуса проверки , подсчёт общего количество проверок, сохранение данных в JSON-файл,загрузка данных из JSON-файла,проверка правильности данных,проверкаа работы функциии
Статус проверок :
pending - проверкаа ожидает выполнения
pass - провера пройдена
fail - проверка не пройдена
Файлы проверок :
cases.py - функции для работы с проверками
storage.py - загрузка и сохранение данных
main.py - главное меню программы
checks.py - проверка работы функций
cases.json - файл с основными данными
check-cases.json-файл для проверок сохранения
example-cases.json-пример проверок
Запуск программы : python main.py
Запуск проверок : python checks.py
